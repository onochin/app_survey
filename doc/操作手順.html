01

現在の完成版をすぐに起動する

トラバース測量そのものを先に理解したい場合 図で学ぶ「トラバース測量 入門」 を先に読むと、観測値、方位角、閉合差の意味が分かりやすくなります。

パソコンを再起動した後は、ターミナルを開いて次の2行を実行します。 ソースコードを更新していなければ、毎回ビルドする必要はありません。 

cd ~/ai_proj/app_simulation/survey-learning-lab
npm run preview

ターミナルに表示されたURLをブラウザで開きます。通常は http://localhost:4173/ です。

起動できた状態 ターミナルに Local: http://localhost:4173/ と表示され、ブラウザに「閉合多角測量シミュレーター」が表示されます。
ターミナルは起動中のままにします ブラウザのタブを閉じてもサーバーは動き続けます。完全に終了するには、 起動したターミナルで Ctrl + C を押します。

03

ビルドと更新の手順

初回またはソースコードを更新した後

  1. 動いているサーバーを終了する 開発版またはビルド版を起動したターミナルで Ctrl + C を押します。
  2. プロジェクトへ移動する 
    cd ~/ai_proj/app_simulation/survey-learning-lab
  3. 型と計算ロジックを検証する 
    npm run typecheck
npm test
    エラーがなく、テストがすべて passed になることを確認します。
  4. 本番用ファイルを作り直す 
    npm run build
    成功すると、更新されたファイルがdist/へ生成されます。
  5. ビルド版を起動して確認する 
    npm run preview
    表示されたURLをブラウザで開き、更新内容を確認します。
ビルドと公開は別です npm run buildとnpm run previewは、 このパソコン内で生成・確認する処理です。インターネットへの公開は行いません。

05

初めて使うときの操作

最初は測点も数値も変更しなくて大丈夫です

このアプリには、最初から計算できるサンプル観測値が入っています。 1回目はそのまま8ステップを進め、全体の流れをつかむのがおすすめです。 測点のドラッグや数値変更は、2回目の練習で試します。

練習1：サンプルをそのまま計算する

  1. 何も変更せず、右側のSTEP 1を見る 最初は「観測角」です。「使用する式」「代入した数値」「計算結果」を上から読みます。
  2. 青い「次へ：ステップ2」を押す 右側の計算内容が「角度閉合差」に変わり、ステップ一覧の現在位置も移動します。
  3. 同じ操作でステップ8まで進める 各ステップで式と結果を読んでから「次へ」を押します。 途中で「計算簿」タブを開くと、到達した項目が順番に表示されます。
  4. ステップ6で誤差を図にする 「誤差の見える化」タブを押します。本来の閉合点と、計算上の閉合点のずれを確認します。
  5. ステップ8の後に確認問題へ回答する 「確認問題」タブで回答を選び、「回答を確認する」を押します。 正解すると学習の流れが完了します。
  6. 「リセット」で最初に戻す 2回目の練習に入る前に、仮想現場図の下の「リセット」を押します。

仮想現場図と右側の計算欄。画像をクリックすると画面全体を原寸で確認できます。

練習2：測点を動かして図の変化を見る

  1. P1、P2、P3、P4のどれかをクリックする 選択した点の名前と「理論内角／観測内角」が、現場図の下に表示されます。 AとBは既知の固定点なので動かせません。
  2. 選択した点をゆっくりドラッグする 点につながる線、黒い理論距離、緑の理論内角が変わります。 辺が交差しない範囲で動かしてください。
  3. 観測手簿の「理論」を見比べる 図形から計算される理論値は変わりますが、入力済みの観測値は自動では変わりません。 これにより、理想的な図形と実際の観測値の差を比較できます。
理論値とは

画面上の測点配置から幾何学的に求めた距離・内角です。 P1〜P4をドラッグすると変わります。

観測値とは

現場で測ったと想定する入力値です。測点をドラッグしても変わらず、 観測手簿で編集します。

練習3：観測値を変更して計算し直す

  1. 「観測値を編集」を押す 仮想現場図の右下にあるボタンです。観測手簿まで自動的に移動します。
  2. 初期方位角 A→P1を確認する 北を0度として時計回りに測った方向を、十進度で入力します。 入力範囲は0度以上360度未満です。
  3. 1つの観測角または距離を少しだけ変更する 観測角は0度より大きく360度未満、距離は正の数です。 まずは1項目だけ変更すると、結果との関係を追いやすくなります。
  4. 右側のSTEP 1から再計算する 入力を変更すると計算ステップは自動的にSTEP 1へ戻ります。 「次へ」を順番に押し、閉合差がどう変わったか比較します。

観測手簿。上段が初期方位角、各行が測点ごとの観測角と次の点までの距離です。 画像をクリックすると画面全体を原寸で確認できます。

値を変更したらSTEP 1へ戻るのは正常です 入力条件が変わると、それまでの計算結果は使えないためです。 新しい観測値で8ステップを最初から確認してください。

06

8つの計算ステップ

各ステップでは「使用する式」「代入した数値」「計算結果」に加え、 必要な理由とよくある間違いを確認できます。

STEP 項目 確認する内容
1 観測角 AからBまで、巡回順に6つの観測内角を確認します。
2 角度閉合差 観測内角和と理論内角和との差を求めます。
3 角度補正 角度閉合差を各観測角へ均等に配分します。
4 方位角 A→P1の初期方位角から各辺の方位角を求めます。
5 緯距・経距 距離を北方向のΔXと東方向のΔYへ分解します。
6 座標閉合差 fx、fy、合成閉合差f、閉合比を求めます。
7 座標補正 コンパス法で閉合差を辺長に比例配分します。
8 新点座標 補正後の成分を順次加算し、各点の座標を確定します。

計算簿の未到達項目は「—」で表示されます。ステップを進めると順番に開示されます。

07

閉合差の見える化と確認問題

誤差の見える化

  • ステップ6へ到達すると「誤差の見える化」タブが表示可能になります。
  • 本来の閉合点と計算上の閉合点、X方向のfx、Y方向のfy、合成値fを確認します。
  • 図の誤差ベクトルは見やすさのため100倍で表示されます。数値欄は実際の値です。
  • 閉合差が非常に大きい場合は、100倍したベクトルが図枠へ収まるよう自動調整されます。

学習を完了する

  1. ステップ8まで進める 右側のボタンが「全8ステップ完了」になったことを確認します。
  2. 「確認問題」タブを開く 閉合差が大きくなる原因について、4つの選択肢から回答します。
  3. 回答を選び「回答を確認する」を押す 不正解の場合は解説を読み、選び直せます。正解すると学習フローが完了します。
08

警告・困ったとき

表示・状態 対応
観測辺が交差しています P1〜P4を動かし、辺が交差しない単純な閉合多角形に戻します。交差中は計算を進められません。
測点同士が近すぎる 選択中の点を、他の測点から少し離れた位置へ動かします。
入力値を修正してください 「観測手簿」の赤く表示された入力欄と、その下の説明を確認します。
4173を開けない npm run previewを実行したターミナルが動いているか、表示されたURLが別のポートになっていないか確認します。
修正が反映されない Ctrl + Cで終了し、型チェック、テスト、ビルド、previewを順に再実行します。
最初からやり直したい 仮想現場図の下にある「リセット」を押します。
入力内容は保存されません この初期版には学習履歴の保存機能がありません。リセット、ページの再読み込み、 またはサーバーの終了により、画面上の操作内容は初期状態へ戻ります。
09

終了前の確認

  • 必要な計算結果を画面で確認した
  • 入力内容が保存されないことを確認した
  • 起動したターミナルで Ctrl + C を押した
  • ターミナルに戻ったことを確認してブラウザを閉じた
