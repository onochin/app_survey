この章はGNSS教材全体の重要な基礎章です。

# 8. カード3「電波が届くまでの時間から距離を考える」

このカードでは最初に明示的に、

> まず、時計のずれや大気の影響がない「理想的な場合」で考えてみます。

と表示してください。

教材用の電波速度：

```text
約300,000 km/s
```

初期到達時間：

```text
70 ms
```

初期計算：

```text
70 ms = 0.070 s

距離
≈ 電波の速さ × 到達時間

≈ 300,000 km/s × 0.070 s

≈ 21,000 km
```

## 操作

到達時間を変更できるスライダーを実装してください。

目安：

```text
65 ms ～ 85 ms
```

例：

```text
65 ms → 約19,500 km
70 ms → 約21,000 km
75 ms → 約22,500 km
80 ms → 約24,000 km
85 ms → 約25,500 km
```

到達時間が増えると、

* 距離表示が増える
* 衛星を模式的に遠ざけてもよい

としてください。

図には必ず、

> ※模式図。実際の距離比率ではありません。

を表示してください。

## 時間ずれの感覚

次を表示してください。

```text
1 ms = 0.001 s

300,000 km/s × 0.001 s
≈ 300 km
```

強調：

> 1 msの違い ≈ 300 km

さらに、

> では、時計がわずか1 μsずれていたら？

と問い、

```text
1 μs → 約300 m
```

を示してください。

## 1衛星では位置は決まらない

1機との距離が分かっても、

> その衛星から一定距離にある場所のどこか

までしか分からないことを模式図で示してください。

ここでは「なぜ4衛星か」の詳解までは行いません。

カード末尾：

> でも現実には、時計も完全ではないし、電波も大気を通ります。この値は本当に「衛星までの真の距離」なのでしょうか？

# 9. カード4「なぜ『擬似距離』なのか？」

カード3の理想世界と現実世界を比較します。

切替：

```text
理想的な場合
現実のGNSS
```

## 時計ずれ操作

教材上の単純モデルとして、受信機時計のずれを変更できるようにしてください。

少なくとも、

```text
0 μs
1 μs
```

を比較できること。

1 μsの場合：

```text
真の幾何学的距離
21,000.000 km

時計ずれに相当する距離
約 +0.300 km

観測される距離に相当する値
約21,000.300 km
```

という関係を理解できるようにしてください。

重要：

> 衛星と受信機の本当の距離そのものが300m伸びたわけではない。

と明示してください。

## 現実の観測に影響するもの

最低限、次を図示してください。

* 受信機時計のずれ
* 衛星時計に関する誤差・補正
* 電離層
* 対流圏
* 衛星軌道に関する誤差
* マルチパス
* 観測ノイズ

ただし、このカードでは各誤差の固定m値を設定しないでください。

条件により変化するものを「常に○m」と誤解させないためです。

定義：

> これらの影響を含む「距離のような観測量」が擬似距離であり、真の幾何学的距離そのものとは限らない。

## なぜ基本的に4衛星以上か

基本的な3次元単独測位の考え方として、

```text
未知量

X
Y
Z
受信機時計ずれ
```

の4つを模式的に示してください。

そのため、

> 位置3成分と受信機時計ずれを求める基本的な3次元単独測位では、少なくとも4機の衛星を利用する。

と説明してください。

連立方程式の詳細は不要です。

整数値バイアス
整数アンビギュイティ

# 12. カード7「擬似距離と搬送波位相を比べる」

新しい概念を大量に追加するカードではなく、カード3～6を整理するカードにしてください。

切替：

```text
コード（擬似距離）
搬送波位相
```

同じ衛星・同じ受信機を使います。

## 擬似距離

> コードの到達タイミングを見る。

## 搬送波位相

> 波の1周期の中の位置を細かく見る。

## 操作

同じ受信機を、

```text
0 ～ 約20cm
```

動かせるようにし、両観測量での見え方を比較してください。

例えば5cm動いた場合、

```text
L1 約19cmに対して約0.26波長
```

という搬送波位相の変化を示してください。

擬似距離については、

> 搬送波ほど小さな変化を精密に捉えることを得意としない

程度の表現にしてください。

「コード観測では5cmを絶対に観測できない」等の過度な断定はしないでください。

## 比較表

最低限：

| 項目     | 擬似距離           | 搬送波位相          |
| ------ | -------------- | -------------- |
| 観測     | コードの到達タイミング    | 搬送波の位相         |
| 距離の考え方 | 到達時間から距離に相当する値 | 波長を細かな物差しとして利用 |
| 長所     | 距離全体を把握しやすい    | 非常に細かな変化を観測できる |
| 主な難しさ  | 時計・大気等の影響      | 整数波長数が最初は不明    |
| 高精度測量  | 基本的な観測量        | 特に重要           |

としてください。

重要：

> 擬似距離は不要、搬送波位相だけが正しい

という表現にはしないでください。

最後に、

```text
基準局
├ 擬似距離
└ 搬送波位相

移動局
├ 擬似距離
└ 搬送波位相

↓
相対的な解析
↓
FLOAT → FIX
```

という第1章への接続を模式的に表示してください。

詳細解析は後続章へ残してください。

# 13. カード8「なぜ複数周波数を使う？」

このカードは、

**複数周波数だけ**

を扱います。

複数GNSSはカード9まで混ぜすぎないでください。

最初の問い：

> 同じ衛星を観測するなら、L1だけではだめなのでしょうか？

まず、

> 1周波でもGNSS測位は可能

と明示してください。

## 同じ衛星から複数周波数

模式図：

```text
GPS衛星 G12
   ├ L1
   ├ L2
   └ L5
       ↓
     受信機
```

強調：

> 複数周波数とは、衛星を増やすことではない。同じ衛星から異なる周波数の信号を観測すること。

## 電離層

電離層ON/OFF、または影響あり/なしを視覚的に切り替えられるようにしてください。

重要概念：

> 電離層による影響は周波数によって異なる。

そのため、

```text
L1の観測
+
L2の観測
↓
周波数ごとの差を利用
↓
電離層の影響を推定・低減
```

という考え方を示してください。

## 周波数組合せ

次を切り替えられるようにしてください。

```text
L1のみ
L1 + L2
L1 + L5
L1 + L2 + L5
```

表示：

```text
L1のみ → 1周波
L1 + L2 → 2周波
L1 + L5 → 2周波
L1 + L2 + L5 → 3周波
```

「2周波＝必ずL1+L2」ではないことを理解できるようにしてください。

## 周波数値

補助情報として、

```text
L1 1575.42 MHz
L2 1227.60 MHz
L5 1176.45 MHz
```

を表示して構いません。

ただし、

> 数値の暗記は不要

と明示してください。

## コード・搬送波との関係

非常に重要なので以下を図示してください。

```text
L1
├ コード観測 → 擬似距離
└ 搬送波観測 → 搬送波位相

L2
├ コード観測 → 擬似距離
└ 搬送波観測 → 搬送波位相

L5
├ コード観測 → 擬似距離
└ 搬送波観測 → 搬送波位相
```

強調：

> L1＝擬似距離、L2＝搬送波位相、という関係ではない。

## 注意

> 3周波だから2周波より単純に何倍も精度が良くなる、という意味ではない。

としてください。

複数周波数には、電離層への対応以外にも搬送波解析・アンビギュイティ決定等で利点がありますが、詳細は後続章へ残してください。

# 14. カード9「なぜ複数GNSSを使う？」

このカードはカード8と対になるようにしてください。

最初の問い：

> GPSだけでも位置は求められるのに、なぜQZSS・Galileo・BeiDouなども一緒に使うのでしょうか？

## GNSSの例

最低限：

* GPS
* QZSS（みちびき）
* Galileo
* BeiDou

GLONASSは補助的に紹介して構いません。

重要なのは国名暗記ではなく、

> それぞれ別の衛星測位システム

であることです。

## 操作：利用するGNSSを増やす

チェックまたはボタンで、

```text
GPS
QZSS
Galileo
BeiDou
```

をON/OFFできるようにしてください。

衛星数は実際のリアルタイム値を使わず、

> 教材用の仮想観測時刻

として固定値を使用してください。

外部APIは追加しないでください。

GNSSを追加すると、

> 利用できる衛星候補が増える

ことを視覚化してください。

## 衛星配置

単純な衛星数だけでなく、

```text
一方向に偏った衛星配置
空全体へ分散した衛星配置
```

を比較してください。

説明：

> 衛星数だけでなく、衛星配置も重要。

DOPという用語は、

> 衛星配置の良し悪しに関係する指標

として存在だけ紹介して構いません。

GDOP、PDOP、HDOP、VDOP等の詳解・計算は今回不要です。

## 山地・森林の模式例

切替：

```text
開けた場所
山地・森林
```

などを用意してください。

山・樹木・建物等によって衛星の一部が遮蔽される模式図を表示し、

GPSのみより複数GNSSを利用した方が、利用可能な衛星候補を確保しやすいことを体験させてください。

ただし、

> マルチGNSSなら山林でも必ずFIXする

という表現は禁止です。

衛星遮蔽、樹冠、マルチパス、衛星配置等によって条件は変わることを示してください。

QZSSについては、

> 日本付近で高仰角の衛星を利用しやすくすることを目的とした特徴を持つ

程度の説明にとどめ、常に天頂に衛星が存在するような断定は避けてください。

## カード8との最重要比較

大きく表示してください。

```text
複数周波数
＝ 同じ衛星を異なる周波数で観測

複数GNSS
＝ 異なる衛星測位システムの衛星を利用
```

さらに、

```text
GPSだけ + L1/L2/L5
→ 1衛星系 + 3周波

GPS + QZSS + Galileo
各1周波相当
→ マルチGNSS + 1周波

複数GNSS + 複数周波数
→ マルチGNSS + マルチ周波数
```

という違いを理解できるようにしてください。

## 衛星数と信号数も区別する

例えば、

```text
GPS G12
├ L1
├ L2
└ L5
```

は、

```text
衛星：1機
複数周波数の信号を追尾
```

です。

3衛星ではありません。

一方、

```text
G03 ─ L1
G12 ─ L1
G24 ─ L1
G31 ─ L1
```

なら、

```text
衛星：4機
使用する周波数帯：1種類
```

という違いを表示してください。

## システムごとの信号名

GPS、QZSS、Galileo、BeiDouでは信号名称が完全に同じではないため、

すべてを無理に「L1/L2/L5」という同じ名称へ変換しないでください。

第2章では、

> 衛星系によって信号名称は異なるが、対応する複数の衛星・信号を受信機が利用する。

までで十分です。
