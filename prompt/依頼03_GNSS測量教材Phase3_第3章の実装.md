# 4. 第3章の教材メタデータ

教材名：

```text
GNSS測量
```

章番号：

```text
3
```

章タイトル：

```text
GNSSの座標と高さ
```

安定した章ID：

```text
gnss-coordinate-height
```

副題として必要であれば、

```text
観測した3次元位置を、測量成果へつなげる
```

を使用して構いません。

到達目標：

> GNSSで求めた3次元位置が、緯度・経度・楕円体高、平面直角座標、標高へどのようにつながるかを説明し、成果を使用するときに確認すべき測地系・系番号・座標の時点・高さ基準を判断できる。

章終了時に、利用者が最低限次を説明できることを目標としてください。

* GNSSによる位置は地球を基準とした3次元位置として表現できる
* 地心直交座標と平面直角座標は別物である
* 同じ地点を緯度・経度・楕円体高でも表現できる
* 緯度・経度を平面直角座標X・Yへ投影できる
* JGD2024が何の基準なのか
* 元期と今期がなぜ必要なのか
* 楕円体高と標高がなぜ異なるのか
* ジオイド高が何を表すのか
* アンテナ高の誤りが高さ成果へ影響すること
* FIXだけでは成果全体の正しさは保証されないこと

# 10. カード2「地球を基準にした3次元位置」

このカードでは地心直交座標を扱います。

教材内では平面直角座標のX・Yとの混同を防ぐため、

```text
Xc
Yc
Zc
```

という教材用表記を使用してください。

図には最低限、

* 地球
* 地球中心
* Xc軸
* Yc軸
* Zc軸
* 観測点P1

を表示してください。

模式図：

```text
                  Zc
                  ↑
                  │
             ● P1
            /
           /
Yc  ↙    ●────────→ Xc
       地球中心
```

重要メッセージ：

> 地心直交座標Xc・Yc・Zcと、日本の平面直角座標X・Yは別の座標です。

## 操作

P1の模式位置を、

* 日本付近
* 赤道付近
* 北極寄り

などへ切り替えられるようにして構いません。

切替時にXc・Yc・Zcの値または模式値を連動させ、

> 地球上の位置を、地球中心から見た3つの数値で表せる

ことを理解させてください。

実際の測地変換をリアルタイム外部APIで行う必要はありません。

## 固定サンプル

後述する基準サンプルG0について、GRS80楕円体と教材用楕円体高を使用した教材派生値として、

```text
Xc = -3959340.298 m
Yc =  3352854.354 m
Zc =  3697471.502 m
```

を使用してください。

主表示では、

```text
Xc ≈ -3959 km
Yc ≈ +3353 km
Zc ≈ +3697 km
```

程度を大きく見せ、詳細値を補助表示しても構いません。

この値は、

> 日本経緯度原点の公式な地心直交座標成果

とは表示しないでください。

後述の緯度・経度と教材用楕円体高63.3853 mからGRS80楕円体で算出した**教材派生値**として扱ってください。

地心直交座標変換を純粋関数として実装する場合はUIから分離し、GRS80の長半径・扁平率を明示して単体テストしてください。

ただし、変換公式そのものを利用者へ詳しく暗記させる必要はありません。

# 12. カード4「緯度・経度を平面直角座標へ」

最初の問い：

> 緯度・経度が分かっているのに、なぜ測量ではX・Yを使うのでしょうか？

次の流れを図示してください。

```text
地球は曲面
↓
狭い範囲の測量では平面で扱うと計算しやすい
↓
平面へ投影
↓
平面直角座標 X・Y
```

図では、

```text
曲面上のP1
↓ 投影
平面上のP1
```

を視覚化してください。

平面直角座標の規約：

```text
X：北方向を正
Y：東方向を正
```

を既存教材と一致させてください。

## 固定表示

基準サンプルG0では、

```text
緯度
35°39′29.1572″ N

経度
139°44′28.8869″ E

平面直角座標系
第IX系

X = -37928.1965 m
Y =  -8327.6987 m
```

を使用してください。

このX・Yは既存の「測量の基礎」第2章で国土地理院の測量計算サイトによる往復確認済みの値です。

## 系番号の操作

同じ緯度・経度について、

```text
正しい系
第IX系

別の系
例：第VIII系
```

を切り替えて、

> 同じP1でも使用する平面直角座標系を変えるとX・Yの数値が変わる

ことを体験できるようにしてください。

ただし、**第VIII系等の具体的なX・Yを推測で作らないでください。**

別系の数値を実装する場合は、国土地理院の測量計算サイト等の公的な計算根拠で確認して固定教材値としてください。

確認できない場合は、具体値を無理に表示せず、

```text
系を変えると原点・投影条件が変わるためX・Yが変化する
```

という模式表示に留めてください。

外部APIをアプリ実行時に呼び出さないでください。

# 13. カード5「その座標は何を基準にしている？」

このカードではJGD2024を中心に扱います。

最初の問い：

> 緯度・経度やX・Yが表示されていれば、それだけで測量成果として十分でしょうか？

中心メッセージ：

> 座標値だけではなく、「どの測地系を基準にした座標か」を確認する必要がある。

## JGD2024

教材では、

```text
ITRF
世界規模の位置の基準
↓
JGD2024
日本で測量成果を扱う現在の測地系
↓
GRS80楕円体
```

程度に整理してください。

日本測地系2024（JGD2024）は、ITRFに基づく現在の日本の測地系で、GRS80楕円体を採用しています。JGD2011からJGD2024への名称変更は測地系の定義自体を変更したものではなく、水平位置の緯度・経度や平面直角座標成果は引き継がれています。

この部分は実装時にも国土地理院の現行情報を確認し、古いJGD2011中心の説明へ戻さないでください。

## WGS84

WGS84は、

```text
GPSで使用される座標系
```

として紹介してください。

次のように説明しないでください。

```text
WGS84 = JGD2024
```

名称・役割・定義が同じものではありません。

ただし完全に無関係な座標系のようにも説明せず、

> GNSSの多くの座標系はITRFと整合するよう維持されており、実用上非常に近い関係にある

程度の理解にしてください。

厳密なWGS84⇔ITRF⇔JGD2024の座標変換やエポック変換は今回実装しないでください。

## 操作

座標変換シミュレーターにはせず、成果情報の確認操作としてください。

初期表示：

```text
P1
測位状態：FIX

緯度：……
経度：……
測地系：？？？
```

「測地系を確認」等を操作すると、

```text
測地系：日本測地系2024（JGD2024）
準拠楕円体：GRS80
```

と表示する構成を推奨します。

# 14. カード6「その座標は『いつ』の位置？」

このカードでは、元期・今期と地殻変動を主要テーマとして扱ってください。

今回、元期・今期は発展メモではなく**第3章の主要学習項目**です。

中心定義：

```text
元期
＝ 公表成果の基準となる時点

今期
＝ 実際に観測した時点
```

模式図：

```text
元期の基準点 ●
             \
              \ 地殻変動
               ● 今期の位置
```

重要メッセージ：

> どちらも間違いではない。「いつの位置か」が違う。

さらに、

```text
JGD2024
≠
すべての座標の元期が2024年
```

を明示してください。

## 実際の元期の例

国土地理院の現行の測地成果2024・地殻変動補正体系に従い、実装時に最新の公式情報を確認してください。

教材では少なくとも、

```text
東京都本土等の水平位置成果の基準日
2011年5月24日

標高成果の基準日
2024年6月1日
```

という違いを例示してください。

「JGD2024だから全部2024年」と誤解させないことが目的です。

## 仮想基準点T1

地殻変動量の理解には実在点を使わず、専用の仮想点を使用してください。

例：

```text
仮想基準点 T1

元期
X = 1000.000 m
Y = 1000.000 m

今期
X = 1000.035 m
Y =  999.982 m

ΔX = +0.035 m
ΔY = -0.018 m
```

必ず、

> 地殻変動を視覚的に理解するための仮想値であり、実在地点の変動量ではありません。

と明記してください。

## 操作

例えば、

```text
[ そのまま比較 ]
→ 時点がそろっていない

[ 元期へそろえる ]
→ 同じ基準時点で比較
```

としてください。

セミ・ダイナミック補正については、

> 異なる時点の高精度座標を同じ時点へそろえるための仕組み

までを理解できれば十分です。

具体的な補正パラメータ、補間処理、POS2JGDの実装、外部データ取得は今回行わないでください。

# 15. カード7「GNSSの高さは、なぜ標高ではない？」

最初の問い：

> GNSSでFIXし、「高さ 63.3853 m」と表示されました。この63.3853 mは、そのまま標高でしょうか？

断面図で最低限、

* 地表またはP1
* GRS80楕円体面
* ジオイド面
* 楕円体高 `h`
* ジオイド高 `N`
* 標高 `H`

を図示してください。

重要メッセージ：

> 楕円体高と標高は、同じP1までの高さでも基準面が異なる。

## 操作

同じP1を固定したまま、

```text
[ 楕円体高 ]
⇄
[ 標高 ]
```

を切り替え、

```text
楕円体高
63.3853 m

標高
26.6800 m
```

を比較してください。

切替時にP1を上下へ移動させないでください。

「地点が変わった」のではなく、「高さを測る基準面が変わった」ことを理解させてください。

## ジオイドの説明

単純に、

```text
ジオイド = 平均海面そのもの
```

と断定しないでください。

初心者向けには、

> 平均海面と整合する、重力を考慮した高さの基準面

として説明してください。

日本の標高が東京湾平均海面を基準とすることも必要最小限で示してください。

# 16. カード8「楕円体高から標高へ」

既存の「測量の基礎」第2章と同じ高さ教材値を使用してください。

```text
楕円体高 h
63.3853 m

ジオイド高 N
36.7053 m

基準面補正量
0.0000 m

教材用標高 H
26.6800 m
```

基本関係：

```text
H = h - N
```

教材値：

```text
26.6800
= 63.3853 - 36.7053
```

## 操作

初期状態：

```text
楕円体高
63.3853 m

標高
```

# 23. 確認問題1：同じ地点の別表現

問題ID例：

```text
gnss-coordinate-height-q01-same-position
```

問題：

> 同じ地点P1について、地心直交座標Xc・Yc・Zcと、緯度・経度・楕円体高が表示されている。最も適切な説明はどれか。

選択肢内容：

* それぞれ別の地点を示している
* 同じ地点を異なる座標の表し方で示している
* Xc・Yc・Zcは平面直角座標X・Yに高さを加えただけである
* GNSSでは緯度・経度しか求められない

正解内容：

> 同じ地点を異なる座標の表し方で示している

正答理由：

> 地心直交座標と、緯度・経度・楕円体高は、同じ3次元位置を異なる座標表現で示すことができる。

誤答ごとの個別理由も実装してください。

# 24. 確認問題2：平面直角座標の系番号

問題ID例：

```text
gnss-coordinate-height-q02-plane-system
```

問題：

> P1の緯度・経度は正しいが、平面直角座標へ変換するときに本来の第IX系ではなく別の系を指定した。最も適切な説明はどれか。

正解内容：

> 同じP1でも、使用する座標系の原点等が異なるためX・Yの値が変わる。

誤答には最低限、

* P1そのものが別の場所へ移動する
* 系番号は表示上の名称だけなのでX・Yには影響しない
* FIXしていれば正しい系番号へ自動修正される

という誤解を含めてください。
