# 2. カード2「衛星から何が届く？」へ追記

GNSS衛星と受信機の通信について、初心者が誤解しないよう明確にしてください。

次の内容を図または短い説明として追加してください。

```text
GNSS衛星
  ↓
測位用の信号を継続的に送信
  ↓
GNSS受信機
  ↓
受信した信号を観測して位置を計算
```

重要メッセージ：

> GNSS衛星は、受信機から「電波を送ってください」という合図を受けて応答しているわけではありません。

> 一般のGNSS測位では、衛星から受信機への一方向の測位信号を受信機が利用します。

さらにカード3の到達時間につながるように、

> 受信機が合図を送り、返事が戻るまでの往復時間を測っているのではありません。衛星が送った信号の送信時刻と、受信機が受け取った時刻の関係から距離に相当する情報を求めます。

と説明してください。

衛星運用用の地上管制局について詳解する必要はありません。

# 3. カード4「なぜ『擬似距離』なのか？」を補強

現在の21,000 kmの例を使い、擬似距離についてさらに直感的に理解できる説明を追加してください。

最低限、次を明示してください。

```text
真の幾何学的距離
21,000.000 km

時計ずれ等の影響を含んだ距離相当の観測値
21,000.300 km

この21,000.300 kmのような
「影響を含んだ距離相当の観測値全体」
が擬似距離
```

誤解防止として、必ず次を入れてください。

> 擬似距離とは「ずれた分の0.300 km」だけを指す言葉ではありません。

> 時計ずれや大気などの影響を含んだ、距離に相当する観測値全体を擬似距離と呼びます。

既存の、

> 衛星と受信機の本当の距離そのものが300 m伸びたわけではない。

という説明も維持してください。

# 4. カード6「なぜ整数波長数が分からない？」を補強

現在の、

```text
10 + 0.35
11 + 0.35
12 + 0.35
13 + 0.35
```

という教材模式例は維持してください。

ただし、

> なぜ最終的に12波長だと分かるのか

が理解できるよう、FLOAT → FIXの前後に次の流れを図示してください。

```text
複数衛星を観測
      ↓
擬似距離などから概略位置を求める
      ↓
搬送波位相を比較・解析
      ↓
整数波長数の候補を絞る
      ↓
FLOAT
「まだ整数値を確定できていない」
      ↓
複数の観測結果の整合性を確認
      ↓
FIX
「整数値を固定解として採用できた」
```

さらに次を明示してください。

> 教材の「12波長」は、実際の受信機が最初から知っている値ではありません。

> 複数衛星・複数周波数・基準局と移動局の観測などを組み合わせ、観測結果が最も整合する整数値を解析して決定します。

教材例の12という数字について、

> 実際には衛星まで約21,000 km、L1波長約19 cmなので、整数波長数は1億程度の桁になる。12は仕組みを理解するための模式値。

という補助説明を追加してください。

## 4-1. 「4衛星」と整数値決定を混同させない

次の注意を追加してください。

> 基本的な3次元単独測位で4機以上の衛星を使う主な理由は、X・Y・Zと受信機時計ずれの4未知量を求めるためです。

> 「4機あれば整数アンビギュイティが決定できる」という意味ではありません。

## 4-2. FLOAT / FIXの表現

初心者向けには、

```text
FLOAT
整数アンビギュイティを整数としてまだ確定できていない状態

FIX
整数アンビギュイティを整数値として固定解にできた状態
```

としてください。

ただし、

> FIX＝解析終了

とは説明しないでください。

FIX後も観測・監視は継続し、条件悪化や衛星遮蔽等によってFLOATへ戻る場合があることを短く補足してください。

既存の、

> FIXは基準局座標、アンテナ高、座標系、マルチパス等の正しさまで保証しない。

も維持してください。

# 5. カード8「なぜ複数周波数を使う？」を整理

現在の、

```text
L1のみ
L1 + L2
L1 + L5
L1 + L2 + L5
```

のボタンを切り替えても説明内容がほぼ同じで、学習上の変化が小さいため、現在の重複した説明表示は1つにまとめてください。

無理にボタン操作を残す必要はありません。

ただし次の基本整理は残してください。

```text
L1のみ        → 1周波
L1 + L2       → 2周波
L1 + L5       → 2周波
L1 + L2 + L5  → 3周波
```

主要メッセージ：

> 複数周波数とは、衛星を増やすことではありません。同じ衛星から異なる周波数の信号を観測することです。

> 電離層による影響は周波数によって異なるため、複数周波数を組み合わせることで、その影響を推定・低減できます。

## 5-1. L2とL5の具体的な違いを記載

利用者は具体的な特徴があった方が覚えやすいため、次を教材本文へ追加してください。

### L2

> 測量など、従来から高精度な2周波GNSSで利用されてきた周波数。L1と組み合わせた2周波観測は、高精度測位で長く利用されてきました。

### L5

> L2より新しい民生向け信号。高い送信電力と広い帯域を持ち、高い性能・信頼性が求められる用途を意識して設計されています。

その上で、

> L1 + L2もL1 + L5も、どちらも2周波観測です。

> L1 + L5だから必ずL1 + L2より高精度になる、という意味ではありません。

としてください。

現在の、

```text
L1 = 擬似距離
L2 = 搬送波位相
```

ではないことを示す説明は維持してください。

## 5-2. みちびきL6

現在のCLAS / みちびきL6の補足は、そのまま残してください。

L6はL1/L2/L5の測距信号と同じ役割ではなく、CLASの補強情報を送る役割であるという現在の説明を維持してください。

衛星測位システムの紹介について、

```text

```

のような抽象的な説明は不要です。

具体的に、

```text
国・地域
システム名
サービス開始年の目安
```

で覚えられる表示にしてください。

主要な全球型4システムとして、最低限次を表示してください。

| システム | 国・地域 | 説明 | 開始年の目安 |
|---|---|---|---|
| GPS | アメリカ | 全球衛星測位システム | 1993年 |
| GLONASS | ロシア | 全球衛星測位システム | 1995年 |
| Galileo | EU | 全球衛星測位システム | 2016年 |
| BeiDou | 中国 | 全球衛星測位システム | 2020年（BDS-3） |

開始年は、各システムで定義が完全に同じではないため、

> 開始年は、初期運用・正式サービス・現在の全球システム開始などを理解するための目安です。

```text
Q1 → B
Q2 → C
Q3 → A
```

A：2問  
B：2問  
C：2問

とし、特定のアルファベットへ偏らない構成にしてください。

- `correctOptionId`等の意味のある正答IDを壊さない
