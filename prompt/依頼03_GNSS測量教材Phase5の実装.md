# 4. 第4章から第5章への接続

第4章では、自前基準局RTKについて、現在の修正後教材で概ね次の流れを学習済みです。

```text
基準局AのGNSS観測
        ＋
移動局P1のGNSS観測
        ↓
2地点の観測を比較
        ↓
AからP1までの位置の差を求める
        ↓
基準局Aの既知座標
        ＋
AからP1までの位置の差
        ↓
P1の成果座標
```

また、第4章では教材用X方向例として、

```text
正しい基準局A.X
1000.000 m

A→P1 X方向差
+12.345 m

P1.X
1012.345 m
```

に対して、

```text
基準局A.X
1000.500 m

A→P1 X方向差
+12.345 m

P1.X
1012.845 m

測位状態
FIX
```

となる比較を学習済みです。

したがって、第5章の入口は、

> **第4章では、基準局座標が誤っているとP1成果もその影響を受けることを学んだ。では、その「基準局座標」はどこから来て、どうやって正しい基準局をつくるのか？**

としてください。

第4章の `+0.500 m` シミュレーションを第5章で再実装しないでください。

# 5. 第5章の教材メタデータ

教材名：

```text
GNSS測量
```

章番号：

```text
5
```

章タイトル：

```text
自前RTK① 基準局をつくる
```

安定した章ID：

```text
gnss-own-base-station
```

到達目標：

> 自前RTKの基準局について、基準となる座標をどのように用意するかを考え、その座標とGNSSアンテナを正しく結び付け、安定してGNSS観測できる基準局を準備する流れを説明できる。

章終了時に、利用者が最低限次を説明できることを目標としてください。

* GNSS受信機を置いただけでは、測量成果として正しい基準局が自動的に完成するとは限らない
* 基準局座標はP1成果の土台になる
* 基準局座標には「どこから得た座標か」という根拠が必要
* 既知点がある場合と、既知点がない場合では考え方が異なる
* サーベイインや単独測位等で得た座標が、既知点成果と自動的に同等になるとは限らない
* 相対的な位置関係を高精度に求めることと、国家座標等へ正しく整合していることは別
* 既知点成果を使用する場合は、点とGNSSアンテナを正しく結び付ける必要がある
* 求心、アンテナ高、固定状態が重要
* 基準局側でもGNSS観測環境が重要
* 基準局の準備後は、その情報を移動局へ届ける必要がある

# 6. 第5章の中心メッセージ

章全体を通して、次を中心メッセージとしてください。

> **正しい基準局をつくるには、基準となる座標を決め、その座標とGNSSアンテナを正しく結び付け、安定して観測できる状態にする必要がある。**

さらに、

> **「GNSS受信機を設置できた」ことと、「測量成果の基準として適切な基準局をつくれた」ことは同じではない。**

と理解できる構成にしてください。

# 13. カード3「基準局座標はどこから来る？」

このカードは第5章の重要カードです。

最初の問い：

> **基準局へ設定する座標には、どのような用意の仕方があるのでしょうか？**

最低限、次の4つを静的に比較してください。

```text
① 既知点の成果を使う
② サーベイイン等で受信機から位置を得る
③ 単独測位で得た位置を使う
④ スタティック等の測量で基準局となる点の位置を決める
```

比較表の例：

| 座標の用意の仕方 | 第5章で理解すること                              |
| -------- | --------------------------------------- |
| 既知点      | すでに成果として与えられた座標を利用する                    |
| サーベイイン等  | 受信機側で基準局位置を求め、基準局座標として扱う方法がある           |
| 単独測位     | GNSSだけでも位置は得られるが、必要な測量成果との整合を別途考える必要がある |
| スタティック等  | 基準局となる点そのものを測量し、その位置を決める方法がある           |

重要：

> **4つを同じ精度・同じ成果価値の方法として並べないでください。**

中心メッセージ：

> **大切なのは「座標値が表示されているか」だけではなく、その座標がどこから得られ、今回必要とする成果の基準として適切かを確認すること。**

さらに、

> **基準局受信機を起動しただけで、国家座標等へ正しく整合した基準局座標が自動的に決まるとは限らない。**

としてください。

## 13.1 サーベイインについて

第5章では存在と考え方を紹介する程度にしてください。

具体的な、

* Droggerの設定画面
* u-bloxの具体アルゴリズム
* Survey-inの最低時間
* 平均化の具体式
* 精度閾値
* TMODE3等の機器設定
* 何分観測すれば何cmになる等の固定表現

は実装しないでください。

機種・ファームウェア等に依存する詳細を推測で確定しないでください。

中心は、

> **受信機側で基準局位置を求める方法があるが、その座標が今回の成果に使用できるかは別途判断する必要がある。**

としてください。

## 13.2 単独測位について

第4章修正後の表現と矛盾させないでください。

単独測位は、

> 基準局や補正サービスからの外部補正情報を使わず、衛星から受信した信号や航法情報を利用して受信機自身で位置を求める

という既習内容を前提としてください。

「単独測位＝何も補正していない」と説明しないでください。

# 15. カード5「既知点がない場合は？」

```text

基準局候補点 B
座標：まだ確定していない
```

問い：

> **BへGNSS受信機を置けば、そのまま測量用の正しい基準局になるのでしょうか？**

単純に「できない」とだけ説明しないでください。

次の考え方を静的な分岐フローで示してください。

```text
基準局候補点B
座標がまだ確定していない
        ↓
何の成果が必要？

├─ 現場内での相対的な位置関係を扱う
│
│  → 仮の基準座標・ローカルな基準で
│    相対関係を扱える場合がある
│
```

# 17. カード7「基準局をどこに置く？」

中心メッセージ：

> **基準局は「座標が正しい場所」に置くだけでなく、GNSSを安定して観測でき、観測中に動かない場所へ設置する。**

最低限、次を確認項目として示してください。

```text
✓ 上空ができるだけ開けている
✓ 建物・壁・金属物等の反射しやすい物の近くを避ける
✓ アンテナを安定して固定できる
✓ 観測中に人や車両等で動かされにくい
✓ 安全に継続して設置できる
```

# 21. 確認問題1「基準局座標の意味」

問題ID：

```text
gnss-own-base-station-q01-coordinate-basis
```

問題：

> 自前RTKで基準局Aを設置した。基準局座標について最も適切な説明はどれか。

選択肢：

A.

> RTKがFIXすれば、基準局座標は自動的に正しい値へ修正される。

B.

> 基準局座標はP1成果の基準になるため、その座標の根拠を確認する必要がある。

C.

> 基準局座標は通信にだけ使われ、P1成果には影響しない。

D.

> 基準局座標はおおよその値でよく、アンテナ高だけ正しければよい。

正解：

```text
B
```

正答理由：

> 自前RTKでは、基準局からP1までの位置の差を基準局座標へ結び付けてP1成果を求めるため、基準局座標が成果の土台になる。その座標がどこから得られたものかを確認する必要がある。

# 23. 確認問題3「既知点がない」

問題ID：

```text
gnss-own-base-station-q03-no-known-point
```

問題：

> 基準局を置きたい場所の近くに利用できる既知点がない。最も適切な考え方はどれか。

A.

> 既知点がなければ自前RTKは一切使用できない。
