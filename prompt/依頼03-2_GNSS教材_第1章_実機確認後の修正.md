# 2. カード2の修正

現在のカード2では、次の5用途を切り替えられるようになっています。

* 電探の測点位置
* オーリスの探査位置
* 深浅測量の基準点・測量点
* ドローンの基準点・検証点

理由：

各用途で最終的に求める成果が、


で共通しており、第1章の学習上、用途を切り替える操作の必要性が低いためです。

# 6. 右上の「正答 A/B/C/D」を削除

現在、回答後の解説欄右上などに、

```text
正答 B
```

のような表示がある場合は削除してください。

回答欄の右上に正答文字を表示する必要はありません。

ただし、

```text
正解
不正解
```

のような回答結果の状態表示を使用している場合、それ自体は残して構いません。

重要：

> 右上の状態表示と、正解の選択肢文字を混同しないこと。

正解の選択肢文字は、後述する解説本文側で表示してください。

---

# 7. 正解表示の新しい形式

回答後の解説欄では、正答理由の箇所を次の順序にしてください。

```text
正解：B

解説
FIXは基準局へ入力した絶対座標の正しさを保証しない。
……
```

つまり、

```text
正答理由
```

という見出しだけではなく、

```text
正解：B
```

を明示し、その後に、

```text
解説
```

として正答理由を表示してください。

問ごとに正解文字は当然異なります。

例：

```text
問1 → 正解：B
問2 → 正解：C
問3 → 正解：B
```

現在の実装データから正答を導出し、UIへ重複してハードコードしないでください。

---

# 8. 誤答ごとの個別解説は必ず維持

現在実装されている、

> 選択肢ごとの誤答理由

は非常に重要な学習機能なので、削除しないでください。

利用者が不正解を選んだ場合は、

1. 不正解であること
2. 正解の選択肢
3. 自分が選んだ誤答が、なぜ違うのか
4. 正解がなぜ正しいのか

が分かるようにしてください。

---

## 8.1 誤答時の推奨表示順

例えば問1でAを選択した場合：

```text
不正解

正解：B

Aを選んだ場合の解説
FIXは基準局座標の入力誤りを自動で直すものではありません。
……

解説
自前RTKでは、基準局と移動局の相対的な位置関係を高精度に求めます。
……
```

見出し文言は現在のデザインに合わせて多少調整して構いません。

ただし、

```text
選択した誤答の個別理由
```

と

```text
正解の解説
```

は区別して表示してください。

---

## 8.2 正答時

正しい選択肢を選んだ場合は、誤答説明は不要です。

例：

```text
正解

正解：B

解説
自前RTKでは……
```

同じBについて、

```text
Bを選んだ場合の解説
```

と

```text
解説
```

を二重表示しないでください。
