# 測量理解ラボ

測量の基礎概念、GNSS測量、閉合トラバース測量を、図、ミニ操作、式、
数値の変化から理解するための学習用Webアプリです。公式を暗記するだけでなく、
現場で何を観測し、どのように計算・点検して成果へつなげるかを段階的に確認できます。

> このアプリは学習用です。実務上の測量成果、公共測量、登記、設計、
> 品質保証を必要とする計算や成果表の作成には使用しないでください。

## 現在利用できる教材

デスクトップ表示では、左メニューの「測量の基礎」または
「GNSS / Drogger」を選ぶと、その教材の章一覧が親項目の下へ表示されます。
章番号と章名から、学びたい章へ直接移動できます。

### 測量の基礎（全9章）

1. 測量の全体像と測点
2. 座標・標高・高さの基準
3. 距離測量
4. 角度・方位角・度分秒
5. TSの据付と観測
6. レベルと水準測量
7. 観測誤差・精度・検査
8. 座標計算と閉合トラバースへの橋渡し
9. 現場計画・記録・機器管理

主な内容は、既知点と新点、平面直角座標と高さ、水平距離・斜距離・高低差、
方位角と水平角、TSの据付・後視・観測、水準測量、偶然誤差・系統誤差・
粗大誤差、座標の正計算・逆計算、閉合差、観測手簿から成果表までの流れです。
第8章から「閉合トラバース測量を開く」で後続教材へ移動できます。

### GNSS測量

第1章「GNSS測量の全体像」、第2章「GNSSは何を観測しているのか」、
第3章「GNSSの座標と高さ」、第4章「GNSS測位方式を比較する」、
第5章「自前RTK① 基準局をつくる」を実装済みです。第6章以降は今後追加します。

既知点Aに自前基準局を設置し、移動局で新点P1を観測する仮想現場を使って、
一般の調査・測量を代表ケースに、現場の9工程、情報の流れ、自前RTK・
ネットワーク型RTK・CLASの違い、`SINGLE → FLOAT → FIX`、FIX後の品質管理を
確認できます。電探、オーリス、深浅測量、ドローンなどは、GNSSを利用する
実務例として文章で紹介します。自前基準局の具体例としてDrogger Pパッケージを
表示しますが、製品操作マニュアルではありません。

第2章では、衛星信号、コード観測と擬似距離、搬送波位相と整数アンビギュイティ、
複数周波数、複数GNSSの違いを、固定教材値を使った9カードの操作で確認できます。

第3章では、地心直交座標、緯度・経度・楕円体高、平面直角座標、JGD2024、
元期・今期、ジオイドと標高、アンテナ高、FIX後の成果条件を10カードで確認できます。

第4章では、単独測位、DGNSS、自前基準局RTK、ネットワーク型RTK、CLAS、
スタティック測量の6方式を9カードで比較します。基準局座標の誤入力がFIXのまま
成果へ伝わる例と、現場条件から検討候補を絞る操作も確認できます。

第5章では、基準局座標の4つの入口、既知点Aの利用、既知点がない場合の分岐、
求心・アンテナ高・固定、基準局側の観測環境、使用前確認を9カードで学びます。
カード2～8は不要な切替操作を設けず、静的比較・模式図・フロー・確認表を使います。

第1章に3問、第2章に7問、第3章に8問、第4章に8問、第5章に8問、
合計34問の確認問題があります。
回答後は、問題データから導出した正解文字、正解の解説、誤答時は選択肢別の理由を
区別して表示します。第1章の工程・方式・測位状態・品質確認、第2章～第4章の
各操作は、教材を往復しても同じ画面を開いている間は保持します。第1章～第5章の
問題回答と理解済み状態も保持しますが、ページ再読込み後は初期化します。
GNSS教材用の学習記録とlocalStorage保存はまだありません。

### 閉合トラバース測量

A、P1～P4、Bからなるサンプルを使い、次を一段ずつ確認できます。

- 測点のドラッグ、観測内角・観測距離・初期方位角の編集
- 角度閉合差と均等補正
- 方位角、緯距・経距、座標閉合差、閉合比
- コンパス法による補正と補正後座標
- 本来の閉合点、計算上の閉合点、`fx`・`fy`・`f`の図示
- 交差辺の警告と計算停止
- 確認問題と学習記録

## 確認問題

測量の基礎には15問あります。

- 基礎確認：9問（各章1問）
- 現場判断：6問（第5章、第7章、第9章）

回答後は、正解・不正解、選択した回答、正答、正答理由、選択肢別の誤答理由、
現場での確認事項を表示します。問題の選択回答と正誤表示は章や教材を往復しても
同じ画面を開いている間は保持しますが、ページ再読込み後は初期化します。

## 基礎教材の学習記録

安定した章ID・問題IDを使い、次の24項目を個別に記録できます。

- 第1章～第9章：9項目
- 確認問題：15項目
- 合計：24項目

各項目では、次を利用できます。

- 「理解できた」「あとで復習」
- 500文字以内のメモ
- 学習回数
- 最終記録日時
- 要復習項目を上に表示する復習一覧
- 復習一覧から対応する章・問題を開く操作

チェック状態とメモは変更時に自動保存します。「今回の学習を記録」を押した
場合だけ、学習回数を1増やして最終記録日時を更新します。確認問題で誤答すると
その問題を自動的に「あとで復習」へ登録し、利用者が解除するまで維持します。
章の「理解できた」は、ページ再読込み後も復元されて章進捗へ反映されます。

### ページ再読込み後に保存される内容

- 基礎教材の理解状態、復習状態、メモ、学習回数、最終記録日時
- 上記から算出する基礎教材の章進捗
- 閉合トラバースの既存学習記録

### ページ再読込み後に初期化される内容

- 基礎教材の問題で選択した回答
- 問題の正解・不正解と理由の表示状態
- 第1章～第9章の通常ミニ操作状態
- GNSS第1～第5章の操作、問題回答、理解済み状態
- 閉合トラバースの測点、観測入力、計算途中の画面状態

## localStorageと保存キー

学習記録はブラウザの`localStorage`へ保存します。基礎教材と閉合トラバースは
別の保存キーと保存形式で管理します。GNSS教材は現時点では保存しません。

```text
survey-learning-lab:basics-learning-records:v1
survey-learning-lab:traverse-learning-records:v1
```

`localStorage`は同一オリジン単位です。たとえば
`http://localhost:5173`と`http://localhost:4173`は別の保存領域です。
普段使用するURLを統一してください。ブラウザのサイトデータを削除すると
学習記録も消えます。

外部API、クラウド同期、ユーザー登録、端末間同期、バックアップ書出し・読込みは
ありません。学習記録を外部サービスへ送信しません。

## インストール

依存バージョンは`package-lock.json`で固定しています。プロジェクト内へ導入し、
グローバル環境は変更しません。

```bash
npm ci --ignore-scripts
```

画面の自動確認も行う場合は、依存関係を確認したうえでブラウザを
プロジェクト内へ導入します。

```bash
env PLAYWRIGHT_BROWSERS_PATH=0 ./node_modules/.bin/playwright install --only-shell chromium
```

ブラウザは`node_modules/playwright-core/.local-browsers/`へ保存されます。

## ローカルでの起動

開発中は次を実行し、表示されたローカルURLをブラウザで開きます。


## 座標軸と方位角

- X座標：北方向を正
- Y座標：東方向を正
- 方位角：北を0度とし、時計回りに0度以上360度未満
- 緯距：`ΔX = S × cos(α)`
- 経距：`ΔY = S × sin(α)`
- 閉合差：`fx = ΣΔX`、`fy = ΣΔY`、`f = √(fx² + fy²)`

角度は内部では十進度で扱い、三角関数へ渡す前にラジアンへ変換します。
計算途中は丸めず、画面表示時だけ必要な桁へ整えます。
