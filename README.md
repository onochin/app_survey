# 測量理解ラボ

閉合多角測量を「見て、操作して、計算して理解する」ための学習用Webアプリです。  
測点や観測値を変えながら、角度閉合差、方位角、緯距・経距、座標閉合差、
コンパス法による補正、補正後座標を一段ずつ確認できます。
あわせて、測量初心者向けの「測量の基礎」を図とミニ操作で学べます。

> このアプリは学習用です。実務上の測量成果、公共測量、登記、設計または
> 品質保証を必要とする計算には使用しないでください。

## 実装済みの範囲

- 「測点と位置」「距離と方向」「高さを比べる」「観測と機器」の基礎4章
- 測点選択、方位角・度分秒、高低差、反復観測、測量機器のミニ操作
- A、P1〜P4、Bからなるサンプル閉合多角測量
- P1〜P4のドラッグと、A・Bの固定
- 図上の理論距離・理論内角と観測値の分離
- 観測内角、観測距離、初期方位角A→P1の編集
- 日本語の入力エラー表示
- 8段階の計算ステップと計算簿
- 角度閉合差の均等補正
- 方位角、緯距・経距、座標閉合差、閉合比
- コンパス法による座標補正と補正後座標
- 本来の閉合点、計算上の閉合点、fx・fy・fのSVG表示
- 閉合差ベクトルの100倍表示
- 辺が交差した場合の警告と計算停止
- 解説付きの確認問題1問
- サンプル状態へのリセット
- 計算ロジックの単体テストとPlaywrightによる画面確認

## インストール

依存バージョンは`package-lock.json`で固定しています。プロジェクト内だけへ
導入し、グローバル環境は変更しません。

```bash
npm ci --ignore-scripts
```

`--ignore-scripts`により、依存パッケージの`preinstall`、`install`、
`postinstall`は実行しません。依存追加・更新時は、正規パッケージ名、
公開元、ライフサイクルスクリプト、既知の脆弱性、lockfile差分を確認して
から実行してください。

画面の自動確認も行う場合は、依存関係の確認後にブラウザをプロジェクト内へ
導入します。

```bash
env PLAYWRIGHT_BROWSERS_PATH=0 ./node_modules/.bin/playwright install --only-shell chromium
```

このコマンドはブラウザを
`node_modules/playwright-core/.local-browsers/`へ保存します。

## 起動・ビルド・更新

### 開発中の起動

```bash
npm run dev
```

ターミナルに表示されたローカルURL（通常は`http://localhost:5173/`）を
ブラウザで開きます。ソースコードの変更が自動的に画面へ反映されるため、
開発・修正中はこちらを使用します。

サーバーを終了するときは、起動したターミナルで`Ctrl+C`を押します。

### 本番用ビルド

型、単体テスト、ビルドを順番に確認します。

```bash
npm run typecheck
npm test
npm run build
```

本番用ファイルは`dist/`へ生成されます。ソースコードを更新していない場合、
パソコンの再起動だけで再ビルドする必要はありません。

### ビルド後の起動

```bash
npm run preview
```

ターミナルに表示されたローカルURL（通常は`http://localhost:4173/`）を
ブラウザで開きます。これは`dist/`の内容を確認するためのローカルサーバーです。
終了するときは`Ctrl+C`を押します。

パソコンを再起動した後も、プロジェクトと`node_modules/`、`dist/`が残って
いれば、次の操作だけで現在のビルドを起動できます。

```bash
cd ~/ai_proj/app_simulation/survey-learning-lab
npm run preview
```

### アプリ更新時の手順

ソースコードを変更した場合は、古い開発・確認サーバーを`Ctrl+C`で終了し、
プロジェクトディレクトリで次を実行します。

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

ブラウザでターミナルに表示されたURLを開き、更新内容を確認します。
`npm run preview`は公開・配信処理ではなく、このパソコン内での確認用です。

## 座標軸と方位角

- X座標：北方向を正
- Y座標：東方向を正
- 方位角：北を0度とし、時計回りに0度以上360度未満
- 緯距：`ΔX = S × cos(α)`
- 経距：`ΔY = S × sin(α)`
- 閉合差：`fx = ΣΔX`、`fy = ΣΔY`、`f = √(fx² + fy²)`

角度入力は十進度、画面上の確認表示は度分秒です。三角関数へ渡す前に
度をラジアンへ変換しています。
